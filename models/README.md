# Fitted pipeline

`pipeline.joblib` is generated by `python -m real_estate.train`. It contains the complete fitted estimator, raw feature contract, schema version, experiment metadata, and library versions. A fitted artifact was used in the private verification environment; the public repository excludes all model binaries regardless of size. Fresh clones must train locally.

The app starts without a model: `/health` and predictions return safe HTTP 503 responses, and the form gives the training command. Train first for useful predictions. Restart the app after replacing an already loaded model.

Only load artifacts you generated or trust: joblib uses executable pickle serialization. The loader requires the exact recorded scikit-learn version and schema. Use `requirements.txt` and retrain after changing dependencies. This is not a cross-version artifact format.

The original 330,836,593-byte Random Forest remains untouched in the historical ZIP. It is not used by this application. No Git LFS setup is required.
