Read this estimate in context

The model learns from historical 2019–2020 Peru sale listings for Casa (house) and Departamento (apartment), priced in USD.

These are advertised asking prices, not completed sale transaction values. The estimate is not adjusted for today's market.

No uncertainty interval or calibration guarantee is available. Missing details and unfamiliar locations can reduce reliability.

Room count and covered area are absent from the retained training data, so this model does not use them.

Sale listings with a blank price period are included under the documented assumption that they represent a one-time asking price.

A local portfolio demonstration · See the repository README for methodology, evaluation, and data limitations.
